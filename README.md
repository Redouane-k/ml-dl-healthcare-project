# R Machine Learning & Deep Learning Portfolio

## 📌 Overview
This repository contains advanced machine learning and deep learning projects implemented in **R** for healthcare and predictive modeling applications. It demonstrates the complete workflow from traditional statistical learning algorithms to modern neural network architectures.

---

## 📁 Project Structure

### 1. Machine Learning (`01_machine_learning/`)
* **Objective:** Implement classical predictive models (such as Random Forest, XGBoost, or Logistic Regression) using R.
* **Key Tasks:** Data preprocessing, feature engineering, hyperparameter tuning, and performance evaluation (ROC-AUC, Precision-Recall).
* **Context:** *Academic project / Advanced Biostatistics*

### 2. Deep Learning (`02_deep_learning/`)
* **Objective:** Build and train deep neural networks using R frameworks (e.g., Keras/TensorFlow or Torch).
* **Key Tasks:** Network architecture design, training optimization, loss monitoring, and validation on complex datasets.
* **Context:** *Academic project / Advanced Biostatistics*

---

## 🛠️ Tech Stack & Libraries
* **Language:** R
* **Machine Learning:** `tidymodels`, `caret`, `randomForest`, `xgboost`
* **Deep Learning:** `keras`, `tensorflow` (or `torch`)
